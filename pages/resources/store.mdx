###### Localized Strings

All fields marked as `string | map[string, string]` may represent possibly localized string.
For maps, the key is [locale](/reference#locales) and the value is localized string.
A string field is considered as not localized.

### Public SKU Object

Public SKUs are superset of [base SKUs](#base-sku-object), and have additional fields as shown below.

###### Public SKU Structure

| Field                  | Type                                               | Description                                                                      |
| ---------------------- | -------------------------------------------------- | -------------------------------------------------------------------------------- |
| bundled_skus? ^1^      | array[[public SKU](#public-sku-object) object]     | The SKUs bundled with this SKU                                                   |
| price                  | [SKU price](#sku-price-structure) object           | The price of the SKU                                                             |
| content_rating_agency? | integer                                            | The [content rating agency](#content-rating-agency) of the SKU in current region |
| content_rating?        | [content rating](#content-rating-structure) object | The content ratings of the SKU in current region                                 |

^1^ Bundled SKUs are SKUs that the user will be entitled to after purchasing the parent SKU.

### Private SKU Object

Private SKUs are superset of [base SKUs](#base-sku-object), and have additional fields as shown below.

| Field             | Type                                                             | Description                                                              |
| ----------------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------ |
| bundled_skus? ^1^ | array[[private SKU](#private-sku-object) object]                 | The SKUs bundled with this SKU                                           |
| price_tier        | integer                                                          | The price tier of the SKU                                                |
| price             | map[string, integer]                                             | The price overrides for specific currencies                              |
| sale_price_tier   | integer                                                          | The sale price tier of the SKU                                           |
| sale_price        | map[string, integer]                                             | The sale price tier overrides for specific currencies                    |
| content_ratings   | map[integer, [content rating](#content-rating-structure) object] | The content ratings of the SKU for each [agency](#content-rating-agency) |

^1^ Bundled SKUs are SKUs that the user will be entitled to after purchasing the parent SKU.
